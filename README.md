# 🎓 EBAC — Atividade do Módulo 23: Listagem de Artigos

## 📖 Sobre

- `data/` — artigos e autores em JSON
- `lib/functions.ts` — funções de acesso/combinação dos dados
- `lib/types.ts` — tipos `Artigo` e `Autor`
- `app/components/` — Title, Body e componentes de página

## 🚀 Como rodar

```bash
npm install
npm run dev
```

## 🛠️ Tecnologias

Next.js • TypeScript

## 💡 O que aprendi

- Modelagem de dados com tipos e JSON estático
- Funções de filtro/relacionamento entre entidades (artigos × autores)
